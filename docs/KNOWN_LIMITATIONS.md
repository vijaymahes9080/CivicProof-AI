# CivicProof AI - Known Limitations & Roadmap

## Current Limitations

1. **Geographic Coverage:** The initial MVP focuses on Central Sector schemes and the state of **Tamil Nadu**. Coverage for additional Indian states (Karnataka, Maharashtra, Andhra Pradesh, Uttar Pradesh) is scheduled for future releases.
2. **Language Coverage:** Currently supports **English** and **Tamil (தமிழ்)**. Hindi, Telugu, Kannada, and Malayalam language models are in development.
3. **Real-Time Portal Downtime:** While CivicProof AI tracks content hashes, it does not monitor real-time server downtime of individual state scholarship portals.

## Roadmap & Milestones

- [x] MVP Core: Central & Tamil Nadu Schemes
- [x] Deterministic Pydantic Rule Engine
- [x] Model Context Protocol (MCP) Server with 7 tools
- [x] Bilingual UI (English & Tamil) with Plain-Language Mode
- [x] 30-Question Grounded Benchmark Suite
- [ ] Expansion to all 28 Indian States & 8 UTs
- [ ] Voice-assisted accessibility for rural applicants
- [ ] Integration with DigiLocker API for client-side certificate hash verification

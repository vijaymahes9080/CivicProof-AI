### 🌟 Key Architectural & Innovation Highlights:

🛡️ **Zero Hallucination with Deterministic Rules**
Unlike traditional AI chatbots that fabricate criteria, CivicProof AI couples Hybrid RAG with deterministic Pydantic rule validation. Answers are strictly anchored to official `.gov.in` gazettes with page numbers and source quotes.

🤖 **Model Context Protocol (MCP) Server with 11 Public Tools**
Integrated with the official Python MCP SDK, exposing read-only tools for scheme comparison, multi-year cashflow calculation, scholarship scam vetting, and district nodal office geolocation.

🎙️ **Bilingual Voice Assistant (English & தமிழ்)**
Empowers rural and low-literacy citizens with Web Speech API speech-to-text input and instant text-to-speech reading in Tamil and English.

🔒 **Zero-Knowledge Gazette Integrity & PII Scrubbing**
Client-side browser SHA-256 hash validator verifies official PDF circulars without uploading citizen documents to the cloud. Automatic regex interceptors redact 12-digit Aadhaar, phone numbers, and bank details.

🌐 **Multi-State & Offline-First Coverage**
Full support for Central NSP scholarships plus state schemes across Tamil Nadu, Karnataka (SSP), Kerala (E-Grantz), Andhra Pradesh (JVD), Maharashtra (MahaDBT), and Uttar Pradesh (Saksham). Built as an offline-first PWA with Service Worker caching!

📊 **Enterprise Observability & Cloud Deployment**
Instrumented with OpenTelemetry distributed tracing, Prometheus `/metrics`, Grafana dashboards, Docker Compose, and Kubernetes Helm charts.
